<section className="font-kode text-terminal-400 space-y-6 mb-12">
  <h2 className="text-2xl font-heading text-terminal-500">Whitelabel by Configuration</h2>
  <p>
    A new client is set up by editing a short list of files. The main one is <code>src/data/branding.yaml</code>, which
    holds the business name, tagline, contact details, social links, SEO defaults, the selected theme and the animation
    level. Fields that must be replaced are flagged with a <code># REPLACE:</code> comment so they can be found with a
    single search.
  </p>
  <ul className="list-disc pl-6 space-y-3">
    <li>
      Navigation, FAQs, CTAs, testimonials, partners and service areas are separate YAML files in <code>src/data</code>.
    </li>
    <li>
      Services, blog posts, careers and locations are Markdown validated by content collection schemas. Each service
      category has a <code>_hub.md</code> file, and new service files generate their pages and search entries.
    </li>
    <li>
      Themes are CSS files in <code>src/styles/themes</code> registered in <code>themes.yaml</code>. A custom theme is
      made by copying an existing one.
    </li>
    <li>
      Logos, favicons, the default Open Graph image and hero images are the remaining assets to swap. The project docs
      estimate a full rebrand at 30 to 60 minutes; I have not independently timed it.
    </li>
  </ul>
  <h2 className="text-2xl font-heading text-terminal-500">Forms, Motion and Search</h2>
  <p>
    Contact forms go through a provider layer: a form controller and validator in <code>src/utils/forms</code> with
    adapters for Web3Forms (the default), SendGrid and Mailchimp. A server route handles submissions, and an environment
    switch separates test recipients from production recipients.
  </p>
  <p>
    The animation engine in <code>src/utils/animations</code> is built on Anime.js with presets for hero, reveal,
    scroll, counter, text and interaction effects. The animation level in the brand file scales these from none to bold.
    Site search uses Fuse.js with a modal and a dedicated search page, driven by a generated index.
  </p>
  <h2 className="text-2xl font-heading text-terminal-500">Status and Access</h2>
  <p>
    The template is functional, but the project plan still lists its last phases (5 to 7) as unfinished, and adding a
    new service category still requires a manual edit to <code>navigation.yaml</code>. SEO work covers canonical and
    social tags, a sitemap and FAQ structured data. These are planned or partial items, not finished features.
  </p>
