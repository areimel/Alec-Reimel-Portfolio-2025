<section className="font-kode text-terminal-400 space-y-6 mb-12">
  <h2 className="text-2xl font-heading text-terminal-500">Architecture and Implementation</h2>
  <p>
    Collectors are kept separate from pure domain logic and from the UI. Sessions are discovered from the registry
    files, and liveness is checked with a signal-zero kill plus, on Linux, the process start time from /proc to avoid
    mistaking a reused PID for a live session.
  </p>
  <ul className="list-disc pl-6 space-y-3">
    <li>
      Usage limits come from the Anthropic OAuth usage endpoint, polled every 60 seconds by default, with backoff and a
      5-second timeout.
    </li>
    <li>
      Burn-rate projection blends 60% recent trend with 40% average and maps the result to UNDER, NEAR LIMIT, OVER, and
      CRITICAL bands. It is most reliable once a few minutes of data exist.
    </li>
    <li>
      The System panel shows CPU, memory, swap, disk, and network sparklines, with extra metrics on Linux such as
      temperatures and pressure stall information.
    </li>
    <li>
      Layout is budgeted by terminal size: the System panel is hidden on short terminals and panels stack on narrow
      ones.
    </li>
    <li>
      Packaging uses tsup for the npm build and Bun compile for standalone binaries (linux-x64, darwin-arm64,
      darwin-x64), with an install script that verifies SHA-256 checksums.
    </li>
  </ul>

  <h2 className="text-2xl font-heading text-terminal-500">Limits and Caveats</h2>
  <p>
    Costs shown are estimates calculated at API list prices from a public price table. They are not actual billing, and
    they can differ from what a Pro or Max subscription is charged. The tool reads local Claude Code session files
    read-only, and it uses the stored OAuth token only for the usage call; the --no-usage-api flag turns that network
    call off.
  </p>
  <p>
    ccstatusboard relies on undocumented Claude Code internals (the session registry, transcript format, and usage
    endpoint), verified against Claude Code 2.1.x, so a Claude Code update may break it. It shows a warning for versions
    it has not been tested against. Windows is not supported, and there is no standalone binary for Linux arm64, where
    the npm install is the option.
  </p>
